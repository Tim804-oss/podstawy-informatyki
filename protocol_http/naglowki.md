# Nagłówki HTTP

## Zapytanie

1. **Host**
    - Określa nazwę hosta serwera, do którego jest kierowane zapytanie.
2. **User-Agent**
    - Informuje serwer o kliencie, który wysyła zapytanie (np. przeglądarka, wersja).
3. **Accept**
    - Określa typy mediów, które klient jest w stanie zaakceptować w odpowiedzi.

## Odpowiedź

1. **Content-Type**
    - Informuje klienta o typie mediów zawartych w odpowiedzi.
2. **Content-Length**
    - Określa długość treści odpowiedzi w bajtach.
3. **Date**
    - Pokazuje dzisiejszą datę oraz czas
